# TextPilot: прогресс разработки

Этот файл фиксирует фактическое состояние проекта относительно
[PRD](./PRD.md). Обновляем его после каждого законченного функционального
среза.

## Принятые решения

- Стек: Rust, Tauri 2, Svelte 5, TypeScript, SQLite.
- JavaScript runtime и package manager: Bun.
- Целевая платформа MVP: Windows.
- Данные хранятся локально.
- Сниппет не требует префикса `/`.
- Фраза раскрывается после точного ввода сниппета и нажатия `Tab`.
- Если сниппет не найден, `Tab` выполняет обычное действие.
- Старые сниппеты с `/` автоматически мигрируют в новый формат.
- Чёрный список приложений исключён из scope.

## Выполнено

### Основа приложения

- Создано Tauri-приложение с Svelte-интерфейсом.
- Настроена production-сборка через Bun.
- Добавлена иконка в системном трее.
- Закрытие главного окна сворачивает приложение в трей.
- В трее доступны открытие окна, пауза и полное завершение приложения.
- Tray mode вручную проверен пользователем 2026-06-07.
- Подключено SQLite-хранилище и автоматическое создание базы.
- Системный ввод отключается в password-полях, определённых через Windows UI Automation.
- Подавленные hook клавиши возвращаются исходному приложению при работе в password-поле.
- При первом запуске создаётся профиль `Основной`.
- Реализован главный экран с навигацией, категориями, поиском и карточками
  фраз.
- Главный интерфейс автоматически ожидает регистрацию Rust state при запуске.
- Скрытые служебные окна не выполняют команды до первого реального показа.
- Системные подтверждения удаления заменены встроенными диалогами TextPilot.
- Селекты категорий используют единый интерфейс с клавиатурной навигацией.

### Профили

- Создание профиля с автоматическим переключением на него.
- Переименование профиля.
- Ручное переключение активного профиля.
- Быстрое переключение профиля через dropdown в верхней панели.
- Изоляция категорий, фраз, сниппетов и словаря между профилями.
- Удаление профиля вместе со связанными данными.
- Защита от удаления единственного профиля.
- Отображение количества категорий, фраз и слов в каждом профиле.
- Обновление глобального индекса сниппетов после переключения и удаления.

### Категории

- Создание корневой категории.
- Создание вложенной категории с выбором родителя.
- Отображение категорий как дерева с уровнями вложенности.
- Переименование категории с обновлением путей всего поддерева.
- Удаление категории вместе с дочерними категориями.
- Фразы из удалённой ветки сохраняются и переходят в `Без категории`.
- Отображение категорий и количества фраз.
- Фильтрация списка фраз по категории и всему её поддереву.
- Перемещение фразы между категориями через редактирование фразы.

### Фразы и сниппеты

- Создание фразы с названием, сниппетом, категорией, текстом и описанием.
- Редактирование всех полей фразы.
- Включение и выключение отдельной фразы.
- Удаление фразы с подтверждением.
- Поддержка многострочного текста.
- Поиск по названию, сниппету, содержимому и описанию.
- Глобальный Windows keyboard hook.
- Вставка фразы по обычному сниппету и клавише `Tab`.
- Регистронезависимый поиск сниппета.
- Режим паузы.
- Обновление активного индекса после создания, изменения, отключения и
  удаления фразы.

### Словарь

- Добавление правильного слова.
- Редактирование и удаление слова.
- Назначение категории и перемещение между категориями.
- Приоритет слова от 0 до 100.
- Общий флаг активности слова.
- Отдельные флаги автокомплита и автокоррекции.
- Быстрые переключатели параметров в списке.
- Поиск и фильтрация по дереву категорий.
- Уникальность слова внутри профиля.
- Автоматическая миграция существующей базы для флага активности.

### Автокомплит

- Глобальное отслеживание текущего слова через Windows keyboard hook.
- Поиск подсказки после ввода минимум двух букв.
- Использование только активных слов с включённым флагом автокомплита из текущего профиля.
- Сортировка кандидатов по приоритету, длине слова и алфавиту.
- Отображение до шести подходящих слов в отдельном окне рядом с системной кареткой.
- Выбор кандидата глобальными клавишами `↑` и `↓`.
- Наведение мыши меняет выбранный кандидат, щелчок вставляет его.
- `Esc` закрывает список, `Tab` принимает выбранный вариант.
- При вставке добавляется только недостающая часть слова.
- Окно подсказки не получает фокус у исходного приложения.
- Размер и положение окна учитывают DPI и рабочую область текущего монитора.
- При нехватке места снизу список автоматически появляется над кареткой.
- Горизонтальная позиция ограничивается границами текущего монитора.
- Для современных приложений позиция каретки дополнительно определяется через Windows UI Automation.
- Если приложение не отдаёт каретку, окно привязывается к сфокусированному полю ввода.
- Курсор мыши не используется для позиционирования подсказок.
- Точный сниппет имеет приоритет перед автокомплитом.
- Без подходящего сниппета или слова `Tab` выполняет обычное действие.
- Подсказка скрывается при паузе, смене окна, навигации и смене активного профиля.
- Индекс автокомплита обновляется после сохранения и удаления слов.

### Автокоррекция

- Проверка последнего русского слова после `Space`, `Enter`, `Tab` и знаков препинания.
- Поиск кандидатов только среди активных слов текущего профиля с включённой автокоррекцией.
- Сравнение через Damerau–Levenshtein с поддержкой перестановки соседних букв.
- Слова до четырёх букв не исправляются.
- Для слов длиной 5–7 букв допускается расстояние 1, для более длинных слов расстояние 2.
- Уже правильные слова не изменяются.
- При нескольких одинаково близких кандидатах автоматическая замена не выполняется.
- При замене сохраняется регистр исходного слова.
- Последняя автокоррекция или принятое автодополнение отменяется через `Ctrl + Z`.
- Индекс автокоррекции обновляется после изменения словаря и смены профиля.

### Быстрый поиск фраз

- Глобальная горячая клавиша `Alt + Space`.
- Повторное нажатие горячей клавиши закрывает окно и возвращает фокус.
- Событие горячей клавиши отделено от обычного пробела на уровне Windows hook.
- Отдельное компактное окно поверх приложений.
- Общий поиск по фразам и словам пользовательского словаря.
- Поиск по названию, сниппету, слову, содержимому фразы и пути категории.
- В результатах показываются тип, название, фрагмент текста, категория и сниппет.
- Учитываются только включённые фразы и активные слова текущего профиля.
- Навигация по результатам клавишами `↑` и `↓`.
- Вставка выбранной фразы по `Enter` или щелчку мыши.
- Поддерживается вставка многострочных фраз.
- `Esc` закрывает поиск и возвращает фокус в исходное приложение.
- После выбора фразы фокус возвращается в исходное поле ввода.

### Импорт и экспорт

- Экспорт активного профиля или всех профилей в JSON версии 1.
- Экспорт сохраняет категории, фразы, сниппеты, описания, словарь и рабочие флаги.
- Перед экспортом открывается системный диалог выбора папки и имени JSON-файла.
- Перед импортом показывается количество профилей, категорий, фраз, слов и конфликтов.
- JSON с одним профилем импортируется в текущий активный профиль.
- JSON с несколькими профилями сопоставляется с существующими профилями по имени.
- Для конфликтов доступны глобальные стратегии: пропустить или перезаписать.
- Старые сниппеты с префиксом `/` при импорте автоматически переводятся в новый формат.
- Импорт валидируется до записи и применяется одной SQLite-транзакцией.
- Перед каждым импортом создаётся SQLite backup в папке `backups` рядом с базой.
- После импорта обновляются индексы сниппетов, автокомплита и автокоррекции.
- Доступен список SQLite backup и восстановление выбранной версии всей базы.
- Перед восстановлением создаётся страховочный backup текущего состояния.
- Backup относится ко всей базе и всем профилям, а не к отдельному профилю.
- Для активного профиля можно вручную создавать отдельные JSON-снимки.
- Снимки профилей изолированы по `profile_id` и не пересекаются между профилями.
- Восстановление профильного снимка заменяет только категории, фразы и словарь выбранного профиля.
- Перед восстановлением профиля автоматически создаётся страховочный снимок этого же профиля.

### Миграции

- Схема базы данных переведена на обычные сниппеты без `/`.
- Существующие значения вида `/кп` мигрируют в `кп`.
- Сниппеты и слова получили Unicode-нормализованные ключи для уникальности без учёта регистра.
- Старые неоднозначные дубликаты по регистру сохраняются, но автоматически отключаются.
- SQLite запрещает межпрофильные связи категорий, фраз и слов.
