# Компактный интерфейс

Правки по четырём скриншотам:

1. Категория — значок папки и короткое имя рядом с названием; полный путь доступен при наведении. «Без категории» в карточках не выводится.
2. В просмотре фразы крупные кнопки заменены иконками редактирования, включения/выключения и удаления с подсказками. Сокращены отступы и убраны повторяющиеся подписи.
3. Из строк словаря убраны три переключателя. Автодополнение и автокоррекция настраиваются в редакторе; включение слова также доступно через меню.
4. Существующая иконка проекта подключена в боковую панель, настройки и быстрый поиск.
