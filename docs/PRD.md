## 1. Рабочее название

**TextPilot**

Альтернативные названия:

```text id="dnd0oo"
WorkT9
QuickPhrase
TypeMate
SnipPilot
TextMate
```

## 2. Краткое описание продукта

TextPilot — это локальная Windows-утилита для быстрого ввода часто используемых рабочих фраз, автодополнения слов и автоматического исправления опечаток.

Пользователь создаёт профили, категории, фразы, сниппеты и список часто используемых правильных слов. Программа работает в фоне, отслеживает ввод текста, вставляет фразы по сниппетам и исправляет ошибки в словах из пользовательского словаря.

Пример:

```text id="zoowku"
/кп → Здравствуйте! Отправляю вам коммерческое предложение.

комерческое → коммерческое
саглосование → согласование
предлажение → предложение
```

## 3. Цель продукта

Сократить время на ввод повторяющихся рабочих сообщений и уменьшить количество опечаток при наборе текста.

Продукт должен быть:

```text id="btkaxc"
быстрым
локальным
предсказуемым
настраиваемым
безопасным
не раздражающим пользователя
```

Главный принцип:

> Программа помогает писать быстрее, но не пытается думать за пользователя.

## 4. Проблема

Пользователь часто пишет одни и те же рабочие фразы, термины и формулировки.

Из-за этого возникают проблемы:

```text id="kg8o00"
много ручного набора
частые опечатки
повторение одних и тех же сообщений
сложно быстро переключаться между разными рабочими контекстами
нужно помнить большое количество шаблонов
```

Обычный автокорректор слишком общий и часто исправляет не то. Обычные сниппет-менеджеры не исправляют ошибки в пользовательском словаре. TextPilot объединяет оба подхода.

## 6. Основные сценарии использования

### 6.1. Быстрая вставка рабочей фразы

Пользователь печатает сниппет:

```text id="34fmbo"
/кп
```

После подтверждения программа заменяет его на полную фразу:

```text id="kb8405"
Здравствуйте! Отправляю вам коммерческое предложение.
```

### 6.2. Вставка многострочной фразы

Фразы должны поддерживать переносы строк.

Пример:

```text id="u0m7s1"
Здравствуйте!

Отправляю вам коммерческое предложение.
Если возникнут вопросы — напишите, пожалуйста.
```

### 6.3. Автоматическое исправление ошибки

Пользователь добавил в словарь правильное слово:

```text id="id25f1"
согласование
```

Потом случайно написал:

```text id="q71uuv"
саглосование
```

После пробела программа автоматически исправляет:

```text id="ooojyq"
саглосование → согласование
```

### 6.4. Автокомплит частого слова

Пользователь начал вводить:

```text id="i6b3p4"
комм
```

Программа предлагает:

```text id="l6ourr"
коммерческое
```

Пользователь принимает подсказку клавишей.

### 6.5. Отмена автозамены

Если программа исправила слово или вставила автокомплит, пользователь может отменить действие одним нажатием.

Пример:

```text id="kisk1n"
саглосование → согласование
Ctrl + Z → саглосование
```

### 6.6. Переключение профиля

Пользователь вручную выбирает активный профиль.

Например:

```text id="md7mq4"
Типография
Разработка
Личные сообщения
Техподдержка
```

После переключения меняются:

```text id="xq6kmu"
фразы
сниппеты
категории
словарь частых слов
правила автокомплита и автокоррекции
```

Автоматическое переключение по приложению в MVP не требуется.

### 6.7. Экспорт конфигурации

Пользователь может экспортировать:

```text id="dcrh5x"
один профиль
все профили
```

Экспорт создаёт файл конфигурации, который можно переслать другому человеку или перенести на другое устройство.

### 6.8. Импорт конфигурации

Пользователь выбирает файл конфигурации.

Программа показывает предварительный результат:

```text id="bsgg7o"
Будет импортировано:
- профилей: 1
- категорий: 8
- фраз: 32
- слов: 140

Найдены конфликты:
- сниппеты: 4
- слова: 12
```

При конфликтах пользователь выбирает один из вариантов:

```text id="ne2hkt"
Перезаписать все конфликты
Пропустить все конфликты
Отменить импорт
```

## 9. Продуктовые решения

### 9.1. Формат сниппетов

Сниппеты должны использовать обязательный префикс `/`.

Примеры:

```text id="g850u0"
/кп
/сроки
/оплата
/макет
/рекв
```

Сниппеты без префикса не используются.

Причина: это снижает риск случайных замен обычных слов.

### 9.2. Язык

MVP поддерживает только русский язык.

### 9.3. Ошибка раскладки

Исправление ошибочной раскладки не поддерживается.

Пример, который программа не должна исправлять:

```text id="xfi835"
ghbdtn → привет
```

### 9.4. Фразы

Фразы хранятся как plain text.

Обязательно поддерживаются:

```text id="poz0ec"
обычный текст
переносы строк
пустые строки
```

Не обязательно поддерживаются:

```text id="eqxcc1"
Markdown
жирный текст
курсив
таблицы
цвета
ссылки как отдельный rich-text объект
```

### 9.5. Переменные

Переменные не входят в MVP.

Пример, который не поддерживается в первой версии:

```text id="qlc5ly"
Здравствуйте, {name}! Ваш заказ №{order} готов.
```

### 9.6. Автокоррекция

Автокоррекция работает автоматически.

Пользователь не должен вручную добавлять неправильные варианты слов.

Пользователь добавляет только правильные слова:

```text id="nzbpw9"
коммерческое
предложение
согласование
предоплата
ламинация
самоклейка
```

Программа сама определяет похожие ошибки и исправляет их.

## 10. Основные сущности

### 10.1. Profile

Профиль — изолированный набор фраз, категорий, сниппетов и словаря.

Поля:

```text id="l3p42q"
id
name
is_active
created_at
updated_at
```

Действия:

```text id="jvzd96"
создать профиль
переименовать профиль
удалить профиль
переключить профиль
экспортировать профиль
импортировать профиль
```

### 10.2. Category

Категория — способ группировки фраз и слов.

Категории должны поддерживать вложенность по принципу файловой системы.

Пример:

```text id="xuak94"
Типография/
  Клиенты/
    Сроки
    Оплата
    Макеты
  Производство/
    Печать
    Ламинация
  Документы/
    КП
    Реквизиты
```

Поля:

```text id="n5l1zg"
id
profile_id
parent_id
name
path
created_at
updated_at
```

### 10.3. Phrase

Фраза — готовый текст для вставки.

Поля:

```text id="t13mtu"
id
profile_id
category_id
title
snippet
content
description
enabled
created_at
updated_at
```

Пример:

```text id="qxmicp"
title: Срок изготовления
snippet: /сроки
content: Срок изготовления составляет 2–3 рабочих дня после согласования макета.
category: Клиенты/Сроки
```

### 10.4. DictionaryWord

Слово — правильное часто используемое слово.

Пользователь добавляет только правильные слова.

Поля:

```text id="w001rp"
id
profile_id
category_id
word
priority
allow_autocomplete
allow_autocorrect
enabled
created_at
updated_at
```

Пример:

```text id="v1la3b"
коммерческое
предложение
согласование
предоплата
постоплата
макет
тираж
ламинация
самоклейка
```

### 10.5. ReplacementHistory

История последней автозамены нужна для отмены.

Поля:

```text id="bvz2yf"
id
profile_id
action_type
original_text
replacement_text
created_at
```

Типы действий:

```text id="u8tvco"
snippet_replace
word_autocomplete
word_autocorrect
```

### 10.6. IgnoredCorrection

Внутренняя сущность для отменённых исправлений.

Пользователь напрямую её не заполняет.

Если программа исправила слово, а пользователь отменил исправление, программа может временно запомнить:

```text id="ifcgqf"
не исправлять это слово на этот вариант в текущей сессии
```

Поля:

```text id="awxwu0"
id
profile_id
original_text
suggested_text
ignore_scope
created_at
```

MVP-поведение:

```text id="gwtc1n"
запоминать отменённые исправления только до перезапуска программы
```

## 11. Функциональные требования

### 11.1. Профили

Программа должна позволять:

```text id="ma2bbh"
создавать профиль
переименовывать профиль
удалять профиль
вручную переключать активный профиль
экспортировать профиль
импортировать профиль
```

При удалении профиля удаляются связанные категории, фразы и слова.

В системе всегда должен быть минимум один профиль.

### 11.2. Категории

Программа должна позволять:

```text id="brq9bn"
создавать категорию
создавать вложенную категорию
переименовывать категорию
удалять категорию
перемещать фразы между категориями
перемещать слова между категориями
```

Категории отображаются как дерево.

### 11.3. Фразы и сниппеты

Программа должна позволять:

```text id="h9u49k"
создавать фразу
редактировать фразу
удалять фразу
назначать фразе сниппет
включать и отключать фразу
искать фразу по названию
искать фразу по сниппету
искать фразу по содержимому
```

Сниппет должен быть уникальным внутри профиля.

Пример конфликта:

```text id="syz2m5"
/кп уже существует в профиле "Типография"
```

### 11.4. Словарь частых слов

Программа должна позволять:

```text id="vfjap5"
добавлять правильное слово
редактировать слово
удалять слово
назначать слову категорию
задавать приоритет слова
включать или отключать слово
включать или отключать автокомплит для слова
включать или отключать автокоррекцию для слова
```

Слово должно быть уникальным внутри профиля.

### 11.5. Автокомплит

Программа должна:

```text id="wsv3js"
отслеживать текущее набираемое слово
искать совпадения в словаре активного профиля
показывать подсказки
позволять принять подсказку клавишей
не мешать обычному набору текста
```

Автокомплит должен учитывать:

```text id="tw9j1j"
начало слова
приоритет слова
частоту использования
активный профиль
```

### 11.6. Автокоррекция

Программа должна:

```text id="y8pjl6"
автоматически проверять слово после завершения ввода
искать похожие слова в словаре активного профиля
исправлять только при высокой уверенности
не исправлять короткие слова
не исправлять, если есть несколько близких кандидатов
не исправлять слова, которых нет в словаре активного профиля
сохранять последнюю замену для отмены
```

Триггеры проверки:

```text id="avof2f"

Enter

знаки препинания
```

### 11.7. Отмена автозамены

После автозамены пользователь может отменить действие.





## 13. Логика автокоррекции

### 13.1. Общий алгоритм

После завершения слова программа выполняет:

```text id="e1kxna"
1. Получить последнее введённое слово
2. Проверить, что слово русское
3. Проверить минимальную длину
4. Проверить, есть ли слово в словаре
5. Если слово уже есть в словаре — ничего не делать
6. Найти похожие слова в словаре активного профиля
7. Оценить расстояние ошибки
8. Оценить уверенность
9. Если кандидат один и уверенность высокая — заменить
10. Если кандидатов несколько — ничего не делать
11. Сохранить замену в историю
```

### 13.2. Рекомендуемый алгоритм похожести

Для MVP рекомендуется использовать:

```text id="cf03vc"
Damerau–Levenshtein distance
```

Причина: алгоритм учитывает не только замену, удаление и вставку букв, но и перестановку соседних символов.

Примеры:

```text id="x319ab"
макте → макет
пчеать → печать
комерческое → коммерческое
```

### 13.3. Правила безопасности

Рекомендуемые правила:

```text id="qpak0a"
1–4 буквы:
  не исправлять автоматически

5–7 букв:
  исправлять только при расстоянии 1

8–11 букв:
  исправлять при расстоянии 1–2

12+ букв:
  исправлять при расстоянии 1–2
```

Расстояние 3 можно разрешить только позже, после тестирования.

### 13.4. Примеры корректных исправлений

```text id="bku82c"
комерческое → коммерческое
саглосование → согласование
предлажение → предложение
ламинацыя → ламинация
самоклеика → самоклейка
макетт → макет
```

### 13.5. Примеры, которые нельзя исправлять автоматически

```text id="rb1usr"
кот → код
дом → том
мак → знак
акт → арт
```

Причина: короткие слова слишком рискованно исправлять автоматически.

## 17. Структура SQLite

### 17.1. profiles

```sql id="h555n5"
CREATE TABLE profiles (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  is_active INTEGER DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

### 17.2. categories

```sql id="rv7lkv"
CREATE TABLE categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  profile_id INTEGER NOT NULL,
  parent_id INTEGER,
  name TEXT NOT NULL,
  path TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,

  FOREIGN KEY (profile_id) REFERENCES profiles(id) ON DELETE CASCADE,
  FOREIGN KEY (parent_id) REFERENCES categories(id) ON DELETE CASCADE,

  UNIQUE(profile_id, path)
);
```

### 17.3. phrases

```sql id="hj4bb8"
CREATE TABLE phrases (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  profile_id INTEGER NOT NULL,
  category_id INTEGER,
  title TEXT NOT NULL,
  snippet TEXT NOT NULL,
  content TEXT NOT NULL,
  description TEXT,
  enabled INTEGER DEFAULT 1,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,

  FOREIGN KEY (profile_id) REFERENCES profiles(id) ON DELETE CASCADE,
  FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL,

  UNIQUE(profile_id, snippet)
);
```

### 17.4. dictionary_words

```sql id="gq5qbc"
CREATE TABLE dictionary_words (
  id INTEGER PRIMARY KEY AUTOINCREMENT,

  allow_autocorrect INTEGER DEFAULT 1,
  enabled INTEGER DEFAULT 1,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,

  FOREIGN KEY (profile_id) REFERENCES profiles(id) ON DELETE CASCADE,
  FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL,

  UNIQUE(profile_id, word)
);
```

### 17.5. replacement_history


## 19. Импорт конфигурации

### 19.1. Этапы импорта

```text id="r6rxna"
1. Пользователь выбирает JSON-файл
2. Программа валидирует структуру
3. Программа считает количество данных
4. Программа ищет конфликты
5. Программа показывает preview
6. Пользователь выбирает стратегию конфликтов
7. Программа создаёт backup SQLite
8. Программа выполняет импорт
9. Программа показывает результат
```

### 19.2. Стратегии конфликтов

В MVP доступны только глобальные стратегии:

```text id="fthx8v"
перезаписать все конфликты
пропустить все конфликты
отменить импорт
```

Персональный выбор по каждому конфликту не нужен в MVP.

## 21. Поведение вставки текста

Для MVP рекомендуется использовать clipboard-вставку.


## 22. Безопасность и приватность

Программа должна:

```text id="eayhdc"
работать локально
не отправлять текст на сервер
не хранить полный лог ввода
не сохранять пароли
не работать в password-полях
иметь режим паузы
иметь чёрный список приложений
```

Программа не должна:

```text id="lhcp9o"
логировать всё, что печатает пользователь
отправлять данные без согласия
работать скрытно без индикации в трее
мешать пользователю отключить автокоррекцию
```


## 29. Финальная формулировка продукта

TextPilot — локальная Windows-утилита для быстрого набора рабочих текстов. Она позволяет создавать профили, категории, фразы и сниппеты, а также добавлять список часто используемых русских слов. Программа автоматически исправляет опечатки только на основе пользовательского словаря, поддерживает переносы строк во фразах, позволяет отменять автозамену одним действием и переносить настройки через JSON-импорт/экспорт.

Главное отличие продукта: пользователь управляет правильными словами и фразами, а программа аккуратно помогает с вводом, не превращаясь в агрессивный автокорректор.
